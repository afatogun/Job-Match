# JobMatch Embedded Fonts

This folder contains embedded fonts for deterministic CV PDF rendering.

## Families and Versions

- Source Serif 4 (v4.005R)
  - Files: `SourceSerif4-Regular.ttf`, `SourceSerif4-Semibold.ttf`, `SourceSerif4-It.ttf`
  - Upstream release: https://github.com/adobe-fonts/source-serif/releases/tag/4.005R
- Source Sans 3 (v3.052R)
  - Files: `SourceSans3-Regular.ttf`, `SourceSans3-Semibold.ttf`, `SourceSans3-It.ttf`
  - Upstream release: https://github.com/adobe-fonts/source-sans/releases/tag/3.052R

## Why Semibold

Semibold is used for the renderer's bold slot to preserve hierarchy without the heavier visual weight of full bold at CV body sizes.
